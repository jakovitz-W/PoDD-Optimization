# Optimizating Poster Dataset Distillation for Hardware Limitations
## Semester Project for ECE-511 at SIUC

The aim of this project is to determine the efficacy of Poster Dataset Distillation when run on consumer level hardware. Various methods will be tested to improve accuracy, speed, and reduce computational requirements. It will examine the importance of color space, reducing the number of colors, and foreground-aware patch extraction. Implementation will involve modifying and combining existing code-bases from other research studies (listed below).  
		-[PoDD](https://horwitz.ai/podd)  
		-[AutoPallete](https://github.com/KeViNYuAn0314/AutoPalette)  
		-[ColorNet](https://arxiv.org/pdf/1902.00267)  
		-[Dynamic Path Selection](https://arxiv.org/pdf/2601.02727)
